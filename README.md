# DuelForge (nome provvisorio)

Suite desktop per Yu-Gi-Oh!: deck builder con carte e banlist sempre aggiornate, scaffale di deck box 3D personalizzabili, laboratorio statistico (calcolo esatto e Monte Carlo) e Combo Lab, un ricercatore di combo basato sul motore di EDOPro (ocgcore).

Il piano di progetto completo è in [`docs/PIANO.md`](docs/PIANO.md).

Stato: fase di pianificazione.
